# TEDxHSRW Website – HTML Documentation

## Overview
This document describes the structure and functionality of the `index.html` file for the TEDxHSRW website.
The site is implemented as a single-page application (SPA) using HTML, CSS, and Vanilla JavaScript.

## Structure
- Head (metadata, styles)
- Header (navigation)
- Main (pages)
- Footer
- Scripts (routing, events, lightbox)

## Pages
- Home
- Events
- Speakers
- Team
- Sponsors
- Contact

## Key Features
- Custom SPA router using JavaScript
- Dynamic event rendering via EVENTS array
- Lightbox for image viewing
- Responsive navigation with mobile toggle

## Extensibility
- Add pages via navbar + page div
- Add events via EVENTS array
- Add speakers/team/sponsors using year sections
More information and direction about implementing the additions described above can be found inside the .html file in the relevant sections.
